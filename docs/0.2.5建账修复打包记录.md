# 0.2.5 建账修复打包记录

## 目标

将新建账套事务冲突修复编入可运行桌面包，并执行仓库现有 GUI 冒烟测试。本机为 macOS Apple Silicon，因此本次生成 darwin/arm64 包，版本沿用 0.2.5，构建时间用于识别新包。

## 方案与范围

- 使用项目 env.sh 将构建缓存和工具放入工作区。
- 如缺少 Wails CLI，安装与 go.mod 一致的 v2.10.2 到工作区工具目录。
- 使用 build.sh 打包 CLI、macOS .app 和独立桌面可执行文件；检查脚本清理的目标路径确实属于工作区产物目录。
- 执行其内置 GUI 冒烟测试（真实 Vue + jsdom + 打包的 Go 后端），覆盖新建账套等交互。
- 将 .app 压缩为 ZIP 方便获取，核对包和可执行文件。

## 接口、数据流与边界

不改业务接口或数据库结构。源码与前端资源 → Wails 构建 → dist 发布产物 → GUI 冒烟测试。本次不安装到系统应用目录，不操作用户真实账套，不宣称 Windows 或 Intel Mac 包已验证。
